## Install or update manually

1. Download the ZIP for the target version.
2. WordPress admin, **Plugins**, **Add New**, **Upload Plugin**.
3. Choose the ZIP, then **Install Now**.
4. If prompted, confirm **Replace current with uploaded**.

Saved connector settings, orders, and customer data are preserved across an
in-place update. The plugin folder and main file name are unchanged since
v0.3.8, which is what allows WordPress to replace in place.
